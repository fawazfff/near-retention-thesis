Does NEAR keep its users?

An evidence-first study of whether newly active NEAR accounts return to transact, and whether retention is changing across weekly cohorts.

Research status

The analysis pipeline is in place, but no real BigQuery result has been fetched. This page intentionally shows no retention numbers until the source data has been queried and checked.

Run a local preview

  1. Install Python 3.10 or later.
  2. Run python -m unittest -v to check the analysis.
  3. Run python rebuild.py --demo to generate a clearly labelled synthetic dashboard in demo/index.html.

Fetch real data

Install the BigQuery client, authenticate with Google Cloud, then run python fetch_data.py --project YOUR_GCP_PROJECT --dry-run. Review the estimated bytes before running the query without --dry-run. The script enforces a maximum billed-bytes cap.

See the repository README for the complete method, assumptions, tests, and reproduction steps.
